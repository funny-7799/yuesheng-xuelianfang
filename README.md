# 乐声学练坊 · 歌唱课 AI 辅助学习工具

面向中小学歌唱课的免费在线 AI 辅助学习工具，打开网页即可使用，**无需安装、无需注册、无需联网**（音频与练唱数据全部只在本机处理，不上传）。

**在线使用**：https://funny-7799.github.io/yuesheng-xuelianfang/

## 功能一览

| 模块 | 说明 |
|---|---|
| ① 插入学习音频 | 拖入或点选 mp3 / wav / m4a / ogg，支持"原曲欣赏""纯伴奏"等任意槽位，音频只在浏览器本地播放 |
| ② 聆听与循环慢练 | 进度条播放 + A-B 区间循环 + 0.6–1.25 倍速，逐句打磨难句 |
| ③ AI 音准陪练 | 麦克风实时音高曲线（自相关检测），音分偏差读数；练唱时自动播放伴奏（建议戴耳机）；结束即出四维度星级评分与文字练唱报告，可一键复制 |
| ④ 学习任务卡 | 可编辑的聆听/练唱/评议任务卡，一键导出学习单（txt） |

## 课堂典型流程

插入学唱音频 → 原曲欣赏 1 遍（难句设 A-B 循环）→ 学生分句慢练（0.75×）→ 开麦克风"练唱记录"（自动播放伴奏槽位）→ 结束即出星级评分与练唱报告 → 对照曲线互评一处进步与一处待改进。

配套 3 分钟使用指南视频：见本工作区《乐声学练坊·使用指南视频.mp4》。

## 隐私与安全

- 全流程无需联网、无需账号；音频从本机插入，练唱数据只存在浏览器内存，关闭页面即清除。
- 建议用 Chrome / Edge 打开并允许麦克风权限；音箱外放会被麦克风收入，陪练时请戴耳机或清唱。

## 技术说明

- 单文件 HTML（无构建、无依赖），音高检测为时域自相关算法，评分由本机规则依据练唱数据生成，仅作自评参考。
- 本页面通过 GitHub Pages 托管，任何老师均可直接转发链接给学生使用。
